# 2616

a shitty 16-bit cpu

it has:
- 4 registers (a, b, c and d)
- 65536 words of addressible space
- no opcodes (any instruction can take any register as parameters)
- extendable device system
- 14 interrupts
- 29 instructions
- its own assembler language and c-like language
- stack with 255 items
- no flags

see [instructions.md](instructions.md) to see the documentation for the instructions or [assembler.md](assembler.md) to see the documentation for the assembler
